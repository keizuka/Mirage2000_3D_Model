# Modèle 3D du Mirage 2000

Ce dépôt contient les fichiers 3D du modèle **Mirage 2000** spécialement conçu pour une impression 3D sur **Creality Ender 3**.

## Spécifications techniques
- **Envergure** : 1300 mm
- **Longueur** : 2200 mm
- **Moteur EDF** : 120 mm (espace prévu à l'intérieur)
- **Électronique** : Espace prévu pour l'installation
- **Système FPV** : Canopy vide pour installation
- **Train d'atterrissage** : Espace prévu

## Structure des fichiers
Le modèle est divisé en plusieurs fichiers pour faciliter l'impression 3D et l'assemblage.

### Liste des fichiers
1. **`mirage2000_fuselage.stl`** : Fuselage principal avec espace pour le moteur EDF et l'électronique.
2. **`mirage2000_ailes.stl`** : Ailes (gauche et droite) en un seul fichier.
3. **`mirage2000_empennage.stl`** : Empennage (stabilisateurs et gouverne).
4. **`mirage2000_canopy.stl`** : Canopy (vide pour installation FPV).
5. **`mirage2000_train_atterrissage.stl`** : Train d'atterrissage.
6. **`mirage2000_assemblage.step`** : Fichier global pour l'assemblage dans Onshape ou un autre logiciel 3D.
7. **`mirage2000_instructions.pdf`** : Instructions d'assemblage et conseils d'impression.

## Instructions
1. Télécharge tous les fichiers `.stl` pour l'impression 3D.
2. Utilise le fichier `.step` pour l'assemblage dans Onshape ou un autre logiciel.
3. Consulte le fichier `mirage2000_instructions.pdf` pour les détails d'impression et d'assemblage.
